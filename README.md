# Marginmate
[![License](https://img.shields.io/github/license/Drakmyth/Marginmate)](https://github.com/Drakmyth/Marginmate/blob/master/LICENSE.md)

Marginmate is a World of Warcraft addon for identifying potentially profitable products from recipes your characters know.

The addon is under initial development and is not yet functional.

## Installation

1. Download the latest release from the [Releases page](https://github.com/Drakmyth/Marginmate/releases).
1. Navigate to your World of Warcraft installation directory.
1. Extract the release archive into the `_retail_\Interface\AddOns` directory.
1. Start World of Warcraft and make sure `Marginmate` is checked in the AddOns menu.

## Support

Marginmate supports the retail version of World of Warcraft. Other game versions are unsupported.

Report bugs and request features through the repository's [issue tracker](https://github.com/Drakmyth/Marginmate/issues).
